# Government Degree College Adilpur - Official Website Repository

This repository contains the source code for the official website of **Government Degree College Adilpur** (`gdcadilpur.edu.pk`). The website serves as the primary digital portal for students, faculty, administration, and prospective applicants to access academic resources, news, and campus updates.

## 🚀 Features
* **Academic Directories:** Comprehensive information on departments, faculties, and course offerings.
* **Admissions Portal:** Guidelines, eligibility criteria, online registration forms, and fee structures.
* **News & Announcements:** Digital notice board for exams, results, holidays, and campus events.
* **Student Resources:** Quick access to downloads (admission forms, challans, roll number slips).
* **Responsive Layout:** Optimized for seamless viewing across smartphones, tablets, and desktops.

## 💻 Getting Started

Follow these steps to set up and run a local instance of the website for development and testing.

### Prerequisites
* A local development server environment (e.g., **XAMPP**, **WAMP**, or Node.js runtime).
* **Git** installed on your machine.

### Installation & Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project root:**
   ```bash
   cd gdcadilpur-website
   ```
3. **Configure the Local Environment:**
   * Move the project folder into your local server directory (e.g., `htdocs` for XAMPP or `www` for WAMP).
   * Create a local database named `gdc_db` and import the `database.sql` file (if applicable).
   * Update your database credentials in the configuration file (`config.php` or `.env`).
4. **Launch the application:**
   * Open your web browser and navigate to `http://localhost/gdcadilpur-website`
